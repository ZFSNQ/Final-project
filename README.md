随着人工智能和大数据技术的快速发展，Python语言凭借其简洁高效的特性成为了数据分析和机器学习领域的首选工具，Python开发工程师岗位的市场需求也随之不断增长。然而，对于求职者和企业而言，如何科学评估Python开发工程师的薪资水平、了解不同因素对薪资的影响机制仍然是一个值得研究的问题。

### 2.2 数据清洗过程

#### 2.2.1 缺失值处理

```python
# 读取数据
import pandas as pd
df = pd.read_csv('前程无忧数据集.csv')

# 删除第一行（错误的表头）
clean_df = df.drop([0]).reset_index(drop=True)

# 重置列名
clean_df.columns = ['岗位', '公司', '学历', '公司性质', '薪资', 
                   '工作经验_raw', '语言要求', '公司规模_raw', 
                   '公司类型', '公司福利']

# 填充缺失值
for col in clean_df.columns:
    if clean_df[col].dtype == 'object':
        clean_df[col] = clean_df[col].fillna(clean_df[col].mode()[0])
    else:
        clean_df[col] = clean_df[col].fillna(clean_df[col].median())
```

**说明**：由于数据中缺失值较少，且主要为分类变量，因此采用众数填充的方式处理分类变量的缺失值，这种方法能最大程度保持数据的原始分布特征。

#### 2.2.2 薪资数据标准化

```python
import re

# 薪资处理函数
def parse_salary(salary_str):
    salary_str = str(salary_str).strip()
    # 匹配万/月格式
    match_month_wan = re.match(r'(\d+\.?\d*)-(\d+\.?\d*)万/月', salary_str)
    if match_month_wan:
        min_sal = float(match_month_wan.group(1)) * 10000
        max_sal = float(match_month_wan.group(2)) * 10000
        return (min_sal + max_sal) / 2
    # 匹配万/年格式
    match_year_wan = re.match(r'(\d+\.?\d*)-(\d+\.?\d*)万/年', salary_str)
    if match_year_wan:
        min_sal = float(match_year_wan.group(1)) * 10000 / 12
        max_sal = float(match_year_wan.group(2)) * 10000 / 12
        return (min_sal + max_sal) / 2
    # 匹配千/月格式
    match_month_qian = re.match(r'(\d+\.?\d*)-(\d+\.?\d*)千/月', salary_str)
    if match_month_qian:
        min_sal = float(match_month_qian.group(1)) * 1000
        max_sal = float(match_month_qian.group(2)) * 1000
        return (min_sal + max_sal) / 2
    return None

clean_df['薪资_月薪(元)'] = clean_df['薪资'].apply(parse_salary)
clean_df = clean_df.dropna(subset=['薪资_月薪(元)'])
```

**说明**：原始薪资数据格式不统一，包含"万/月"、"万/年"、"千/月"等多种格式。我们将所有薪资统一转换为月薪（元），并取薪资范围的中间值作为该岗位的薪资水平。

#### 2.2.3 工作经验数值化

```python
# 工作经验映射
experience_map = {'无需经验': 0, '1年经验': 1, '2年经验': 2, 
                  '3-4年经验': 3.5, '5-7年经验': 6, 
                  '8-9年经验': 8.5, '10年以上经验': 10}

def parse_experience(exp_str):
    exp_str = str(exp_str).strip()
    for key, value in experience_map.items():
        if key in exp_str:
            return value
    return np.nan

clean_df['工作经验_年'] = clean_df['工作经验_raw'].apply(parse_experience)
clean_df['工作经验_年'] = clean_df['工作经验_年'].fillna(clean_df['工作经验_年'].median())
```

**说明**：将工作经验从分类变量转换为数值变量，取区间中间值作为代表，便于后续的统计分析和建模。

#### 2.2.4 公司规模标准化

```python
# 公司规模映射
size_map = {'少于50人': 25, '50-150人': 100, '150-500人': 325, 
            '500-1000人': 750, '1000-5000人': 3000, 
            '5000-10000人': 7500, '10000人以上': 15000}

def extract_company_size(size_str):
    size_str = str(size_str).strip()
    for keyword in size_map.keys():
        if keyword in size_str:
            return keyword
    return None

clean_df['公司规模'] = clean_df['公司规模_raw'].apply(extract_company_size)
clean_df['公司规模'] = clean_df['公司规模'].fillna(clean_df['公司规模'].mode()[0])
clean_df['公司规模_人数'] = clean_df['公司规模'].map(size_map)
```

```python
from sklearn.metrics import mean_squared_error, r2_score

# 定义模型列表
models = {
    '线性回归': LinearRegression(),
    '岭回归': Ridge(alpha=1.0),
    'Lasso回归': Lasso(alpha=0.1),
    '决策树': DecisionTreeRegressor(max_depth=10, random_state=42),
    '随机森林': RandomForestRegressor(n_estimators=100, max_depth=15, random_state=42),
    '梯度提升': GradientBoostingRegressor(n_estimators=100, max_depth=5, random_state=42),
    'K近邻': KNeighborsRegressor(n_neighbors=10),
    '支持向量机': SVR(kernel='rbf', C=100)
}

# 训练所有模型
results = {}
for name, model in models.items():
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)
    mse = mean_squared_error(y_test, y_pred)
    r2 = r2_score(y_test, y_pred)
    results[name] = {
        '模型': model,
        'MSE': mse,
        'RMSE': np.sqrt(mse),
        'R2': r2
    }
    print(f'{name}: RMSE={np.sqrt(mse):.2f}, R2={r2:.4f}')
```

## 六、结论与建议

### 6.1 分析结论

针对前期规划中提出的问题，我们得出以下结论：

**问题1（描述性分析）**：
- Python开发工程师薪资呈近似正态分布，平均月薪14,850元
- 学历以本科为主（69.5%），工作经验集中在1-4年（85.2%）
- 民营企业是主要雇主（69.5%）

**问题2（探索性分析）**：
- 学历与薪资呈正相关，硕士学历平均薪资显著高于本科
- 公司性质对薪资有显著影响，欧美外资企业薪资最高
- 工作经验与薪资呈现明显的正相关关系

**问题3（洞察性分析）**：
- 工作经验是影响薪资的最重要因素（重要性53.2%）
- 公司规模和公司性质次之（23.2%和16.9%）
- 学历的重要性相对较低（6.7%），说明在该领域实战经验更重要
- 薪资随工作经验增长呈现边际收益递减规律

**问题4（预测性分析）**：
- 可以构建有效的预测模型，线性模型表现最优
- Lasso回归模型的R²达到0.293，RMSE为4,326元
- 模型能够根据学历、经验、公司规模等特征合理预测薪资水平

### 6.2 商业/现实建议

**对求职者的建议**：
1. **重视经验积累**：工作经验是影响薪资的最重要因素，应注重项目实战经验的积累
2. **选择合适平台**：优先考虑欧美外资企业和上市公司，这些企业提供的薪资待遇更优
3. **持续学习提升**：虽然经验更重要，但高学历仍有明显溢价，有条件可以考虑深造
4. **关注行业选择**：金融、互联网等行业薪资水平较高，职业选择时可适当倾向

**对企业的建议**：
1. **制定合理薪资**：参考行业薪资水平，结合工作经验、学历等因素制定有竞争力的薪资体系
2. **重视人才培养**：建立完善的培训体系，帮助新员工快速成长，提高企业竞争力
3. **优化招聘策略**：不过分追求高学历，更应关注实际能力和项目经验
4. **打造雇主品牌**：良好的公司规模和性质形象能够吸引更优秀的人才

### 6.3 不足与展望

**项目不足**：
1. **数据量有限**：仅295条记录，样本量较小，可能影响模型的泛化能力
2. **特征维度有限**：缺少技能要求、地理位置、项目经历等重要影响因素
3. **数据时间跨度短**：仅单一时间点的数据，无法分析薪资的时间趋势
4. **模型解释性有待提升**：虽然有特征重要性分析，但可以进一步深入分析各因素的影响机制

**未来展望**：
1. **扩展数据源**：爬取更多招聘平台的数据，扩大样本量
2. **增加特征维度**：引入技能标签、地区经济指标等更多特征
3. **时间序列分析**：收集历史数据，分析薪资随时间的变化趋势
4. **文本挖掘**：对岗位描述进行文本分析，挖掘技能要求与薪资的关系
5. **模型优化**：尝试集成学习、深度学习等更复杂的模型，提升预测精度
